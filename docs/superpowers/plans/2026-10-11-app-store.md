# Community Software Store Implementation Plan

> For agentic workers: use superpowers:executing-plans to implement this plan task by task. The owner explicitly requested implementation on October 11, 2026. Continue inline without additional planning approval.

**Goal:** Deliver an account-free software catalog with protected approval, Jev search, nightly discovery, cost limits, Discord reports, and self-hosting.

**Architecture:** A shared TypeScript application contains Next.js pages and routes plus a job CLI. PostgreSQL serves production; built-in SQLite provides credential-free local development. Provider calls use server-side adapters and a shared spending ledger.

**Tech stack:** Next.js 16, React 19, TypeScript, PostgreSQL, node:sqlite, Zod, GitHub OAuth, GitHub REST, TypeSafe Jev, Discord webhooks.

**Spec:** ../specs/2026-10-11-app-store-design.md

## Global constraints

- No public accounts, reviews, ratings, personalization, security scans, hosted downloads, or automated installation.
- Every new publication requires owner approval of the reviewed candidate revision.
- USD 20 monthly target. Missing cost configuration disables paid calls.
- Initial categories and platforms match the spec. Missing facts display “Not provided.”
- Use shadcndirectory.com as the UI reference, as requested during implementation: monochrome styling, sidebar filters, compact cards, and responsive layouts.
- Preserve existing workspace files. Git is unavailable under the workspace permissions.

## Review focus

1. An unauthorized user or cross-origin request must not mutate catalog or controls.
2. Overlapping discovery/approval requests must not duplicate apps or publish unreviewed revisions.
3. Concurrent AI calls and timeouts must not release uncertain cost reservations.
4. Provider failure must retain local search and pause affected scheduled work.
5. Transfers, rejected candidates, and missing repositories must not change approved public destinations automatically.
